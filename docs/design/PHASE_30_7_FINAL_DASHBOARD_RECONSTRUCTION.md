# Phase 30.7 — Final Dashboard Reconstruction Map

Goal:
SalonFlowAI dashboard must feel like Apple × Stripe × Linear with Royal Cosmos identity.

Non-negotiable:
- Mobile-first first, tablet/web second
- No random redesign
- Existing components/tokens first
- Each change must improve clarity, hierarchy, speed, or premium feeling

Final dashboard hierarchy:
1. Royal Cosmos background
2. Greeting / business pulse hero
3. KPI cards: revenue, appointments, new clients, growth
4. Revenue / trend analytics
5. AI insights
6. Quick actions
7. Operational health / executive summary

Premium rules:
- One dominant hero zone
- KPI cards must scan in under 2 seconds
- Every card needs consistent padding, radius, border, depth
- Typography must have clear scale: hero > KPI value > label > metadata
- Mobile cards must breathe; no visual crowding
- Actions must look tappable and calm
- AI area must feel alive but not noisy

Acceptance bar:
- iPhone screenshot feels App Store ready
- Android screenshot feels native and premium
- Web/tablet screenshot feels SaaS-grade
- No card feels randomly styled
- No duplicated visual language
