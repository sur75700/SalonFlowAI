# SalonFlow AI — Isolated Logo Asset Generation Request

## Purpose

Define the exact isolated image files needed for final SalonFlow AI production app/store assets.

This document supports Phase 14B-4B.

## Status

Isolated logo asset generation request prepared.

## Important Correction

A brand asset board or presentation image must not be used as an app icon.

The app needs isolated production PNG files, not a full design board.

## Selected Direction

Concept 1 — Royal Flow Monogram.

Visual identity:

- abstract SF monogram
- cosmic orbit
- royal gold
- deep navy / cosmic black
- subtle cyan glow
- premium command-center feeling
- no text inside app icon

## Required Final Files

Generate these separate files:

1. icon.png
   - 1024x1024
   - PNG
   - no text
   - no transparency preferred for iOS safety
   - centered Royal Flow Monogram

2. android-icon-foreground.png
   - 512x512
   - PNG
   - transparent background
   - centered SF/flow mark
   - safe margins

3. android-icon-background.png
   - 512x512
   - PNG
   - deep navy / cosmic black background
   - subtle gradient or glow
   - no text

4. android-icon-monochrome.png
   - 432x432
   - PNG
   - one-color simplified mark
   - no gradients
   - no tiny details

5. splash-icon.png
   - 1024x1024
   - PNG
   - centered mark
   - clean and premium
   - consistent with app icon

6. favicon.png
   - 48x48
   - PNG
   - simplified mark
   - readable at browser tab size

## Do Not Use

Do not use:

- full presentation boards
- logo concept sheets
- screenshots
- text-heavy images
- App Store / Google Play badges
- fake availability claims
- image files with multiple logo options inside one canvas

## Generation Prompt

Create isolated production app icon assets for SalonFlow AI using the selected Concept 1 Royal Flow Monogram direction.

The design should be a premium abstract SF monogram with a smooth flow curve, cosmic orbit, royal gold mark, deep navy/cosmic black background, and subtle cyan AI glow. It must be clean, centered, scalable, readable at small sizes, and suitable for App Store, Google Play, Android adaptive icons, splash screen, and favicon.

No text inside the app icon. No scissors, no combs, no robots, no clutter, no presentation board, no mockup layout.

## Acceptance Criteria

The generated assets are acceptable only if:

- each file is isolated
- each file has the required dimensions
- app icon is readable at small sizes
- Android foreground has transparency
- monochrome version is simple
- favicon is readable
- no presentation layout is included
- no text appears inside the app icon

## Next Step

After isolated files are generated, run dimension checks and replace assets in a separate controlled commit.

## Final Result

SalonFlow AI has a clear isolated logo asset generation request and will not use presentation boards as production app icons.
