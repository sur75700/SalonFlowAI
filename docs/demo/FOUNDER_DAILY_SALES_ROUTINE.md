# SalonFlow AI — Founder Daily Sales Routine

## Purpose

This routine gives the founder a simple daily execution system for turning SalonFlow AI into demos, pilots, and revenue.

The goal is not random effort. The goal is daily visible movement toward first paying salon customers.

## Daily Rule

Every day must move at least one lead forward.

If there is no outreach, no follow-up, no demo push, and no board update, the sales system did not move.

## Morning — Pipeline Control

Do this first:

- Check Git/project only if product work is needed
- Open the first 20 lead board
- Review warm leads
- Review follow-ups due today
- Choose the top 3 leads for the day
- Choose the strongest money task for the day

Morning target:

- Know who must be contacted today
- Know who must be followed up today
- Know which lead is closest to demo or pilot

## Midday — New Outreach

Minimum action:

- Add or verify 3 new leads
- Send 3 first outreach messages
- Use the outreach message pack
- Log every message in the lead board

Strong action:

- Add or verify 5+ leads
- Send 5+ outreach messages
- Personalize the first line for each lead

## Afternoon — Replies and Demo Push

Handle all replies.

Move conversations toward demo using simple next-step questions.

Actions:

- Answer warm replies
- Send demo preview if requested
- Ask for demo time when interest is clear
- Move status to Demo Proposed or Demo Booked
- Send pilot one-pager if the lead asks for details

## Evening — Follow-Up and Scorecard

End-of-day actions:

- Send due follow-ups
- Update every changed lead status
- Count daily activity
- Record bottleneck
- Set tomorrow priority

## Daily Minimum Standard

Every day must include:

- 3 new leads checked or added
- 3 first outreach messages sent
- 2 follow-ups sent
- Lead board updated
- 1 lead pushed toward demo or next step

## Strong Day Standard

A strong sales day includes:

- 5+ new leads checked or added
- 5+ first outreach messages sent
- 3+ follow-ups sent
- 1 warm conversation
- 1 demo proposed or booked

## Lead Status Movement

Move leads through this path:

New -> Contacted -> Replied -> Demo Proposed -> Demo Booked -> Demo Completed -> Offer Sent -> Pilot Candidate -> Closed Won or Closed Lost

## Daily Founder Questions

Ask at the end of each day:

- Which channel performed best today?
- Which message got a reply?
- Which lead is closest to demo?
- What objection appeared?
- What should be improved tomorrow?

## Weekly Review

At the end of the week, review:

- Best outreach channel
- Best message type
- Number of demos proposed
- Number of demos booked
- Strongest lead segment
- Most common objection
- Next product/sales improvement

## Non-Negotiables

- Do not spam
- Do not overpromise
- Track every outreach action
- Follow up respectfully
- Stop if the lead says no
- Focus on demo and pilot movement
- Keep the product proof honest: backend protected, production verified, Android QA prepared

## Founder Close Reminder

The product is already strong enough for demo.

The daily job is to create conversations, learn from salon owners, book demos, and move the best leads toward a pilot.
