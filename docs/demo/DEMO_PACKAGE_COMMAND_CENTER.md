## Workflow Map

Lead research -> Outreach message -> Reply -> Demo proposed -> Demo booked -> Demo completed -> Follow-up -> Pilot candidate -> Close or continue nurturing

## Daily Founder Flow

1. Open FOUNDER_DAILY_SALES_ROUTINE.md
2. Open FIRST_20_LEAD_EXECUTION_BOARD.md
3. Select top 3 leads
4. Use OUTREACH_MESSAGE_PACK.md
5. If lead replies, use DEMO_CLOSE_FOLLOWUP_PACK.md
6. If demo is booked, use PRODUCT_DEMO_SCRIPT.md
7. If lead asks for details, send PILOT_SALES_ONE_PAGER.md

## Minimum Daily Standard

- 3 new leads checked or added
- 3 first outreach messages sent
- 2 follow-ups sent
- Lead board updated
- 1 lead pushed toward demo or next step

## Strong Day Standard

- 5+ new leads checked or added
- 5+ first outreach messages sent
- 3+ follow-ups sent
- 1 warm conversation
- 1 demo proposed or booked
